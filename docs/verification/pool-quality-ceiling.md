# 候選池品質上限的有界驗證

2026-11-22。本輪不修改正式 V1、UI、搜尋、授權篩選或排序，不呼叫新模型、不使用本地模型、不自動重試。

## 預先固定範圍與停止條件

使用 11 月 18 日 final-pool.jsonl 中現行排序的十組攝影完整首批快照，逐張重新檢視；另取 final-zh、final-ja 兩篇未參與正式排序調整的自撰測例，沿用已保存的 V1 詞，各兩方向，共四組。這兩篇曾參與先前 Prompt 留出驗收，並非全新未見歌詞；本次首次完整候選池驗收，不把它們稱為盲測。選擇在取得本輪池之前固定，不依結果挑例。首批為至多 18 張 CC BY 4.0 原始候選，不自動擴頁或混入 CC0。既有 CC0 與來源控制證據只作原因判讀，不與首批上限混算。

完整候選池包含原始回應及授權／媒材篩選後的可用池；排序上限只對可用池計算，不以不合格素材充數。逐張以 0 不相關、1 場景或物件部分相符但情緒不足、2 場景與該方向情緒皆符合評分。未載入列未知，不能當作零分或推斷整池沒有好圖。紀錄所有 2 分作品的排名及逐圖理由。單人目視、非盲測，屬小樣本決策而非人口統計估計。

品質上限為「至少有一張 2 分作品的池數／所有池數」。現有首圖與前三圖命中率均用相同分母。完美排序的首圖及前三圖可達到此上限，差額即純重排最多可提升的百分點；它不是預測模型能實際達成的改善。

只有整體至少 60% 池內有強相關作品，且至少兩池有好圖但落在前三之外，才做一次固定設定的現有 Groq 文字排序對照。這是本輪事前決策門檻，不是普遍標準。未達即停止，AI 呼叫零次，不加案例、不加來源、不改詞。插畫沿用已記錄的來源缺口，不繼續擴大研究。

## 決策

候選池品質僅 50%，未達事前門檻，停止重排研究。雖然兩組有排序改善空間，純重排仍有一半方向拿不到強相關圖片。沒有執行 Groq 對照，AI 呼叫 0、圖片 API 呼叫 4、重試 0、新模型與依賴 0，新增成本 NT$0。

下一階段優先順序：

1. **先改善 V1 短詞到 Commons 查詢的匹配與召回。** 缺圖七組中多組是罕見動作組合或索引誤命中，而非名次差。既有控制證據顯示 night harbor、night alley 能找到夜港與巷道；這只證明場景存在，尚未證明情緒符合。可以固定 V1，另設一次有界、單次請求的通用查詢策略對照，不能做失敗後自動換詞重試，也不建立歌曲對照表。本輪沒有執行或修改該策略。
2. **其次處理仍召回不足的圖片來源與資格證據。** 對改查詢仍缺少情緒畫面的方向，再評估授權清楚的來源覆蓋；原始池中被篩除的近似作品，先核實資格原因，不降低授權標準。不能從有限首批說整個 Commons 沒有好圖，也不能把先前 CC0 可能補圖當成本輪已驗證；現有 CC0 分頁保持原樣，Pexels／Unsplash 仍待適用許可。
3. **排序延後。** 等未參與調整案例的可用池品質足夠，再固定同一池驗證文字語意重排；目前不再增加模型呼叫。插畫維持既有獨立限制紀錄。
