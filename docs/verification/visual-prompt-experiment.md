# 歌詞視覺轉譯 Prompt 的兩輪實驗

2026-11-22。兩輪都未達採用門檻。正式 V1、UI、檢索策略及 API 限額沿用目前版本。本次只新增實驗工具、fixtures 與報告，沒有新增服務、模型下載或付費。結束後不繼續調參。

## 設計與分母

開發比較沿用前輪四首中英日韓自撰歌詞；V1 模型輸出使用已保存的四筆，圖片重新透過正式 Commons adapter 查詢，兩個實驗版本重新推論。同一批詞共用目前首批 CC BY 4.0 搜尋、授權、媒材與排序。沒有將 CC0 提前混排。V1 圖片重播與新模型呼叫有分別標記，這個比較受模型後端版本與重跑日期變動影響。

另在實驗前建立四首未用過的中英日韓原創完整短篇歌詞及預期，保存在 lyrics-final.json。第二輪版本在查看最終案例結果前鎖定，用它與新推論的 V1 配對驗收；第一輪沒有進一步做最終樣本測試。這批留出結果未回饋修改任何提示。

模型為 openai/gpt-oss-20b，temperature 0.1、top_p 1、seed 7、medium reasoning、768 completion tokens、相同 structured output schema。每首兩個方向，各自查攝影及插畫。呼叫序列執行，開發每例相隔至少 60 秒；最終配對每次完成後等 30 秒，單次無重試。模型失敗的案例不發出圖片查詢。兩個實驗提示原文隨工具保存，應用程式沒有切換入口。

強相關需場景與該方向情緒同時吻合。有圖率以每首預期兩個方向為分母，模型失敗列零；另外列明實際圖片請求數。首張、前三張由單人目視，不能證明模型的內部心理理解，也不能外推真實商業曲庫。所有文字為自撰，未使用第三方歌詞。

## 第一輪 A

假設：把心理活動轉成常見場景和可見氣氛，避開罕見的道具及動作組合。

| 開發四例 | V1 | A |
| --- | ---: | ---: |
| 有效模型輸出 | 4/4（前輪保存） | 3/4 |
| 實際攝影／插畫請求 | 8／8 | 6／6 |
| 攝影非空方向（端到端） | 4/8 | 4/8 |
| 攝影首張強相關方向 | 1/8 | 1/8 |
| 攝影前三張至少一張強相關方向 | 1/8 | 1/8 |
| 插畫非空方向 | 0/8 | 0/8 |

中文的 A 收到 HTTP 400，當時尚未記錄供應商 error code，未推測根因，也未重送。英文把「quiet candle flame」換成「quiet room」，確實新增 8 張，但前三是展館、旅館餐廳與作家故居臥室，沒有燭光與敘事轉折。日文「forest trail」有 17 張，前兩張符合安靜森林；「quiet clearing」仍空。韓文「school field dusk」有 3 張，首張是滑板場，另兩張是實驗室；「dark fence」有 10 張，前三是遊樂設施及一般住宅圍欄，未符合黑暗藏身情緒。因此出圖率沒有帶來意境分數提升。

## 第二輪 B

假設：去掉主觀心情形容詞，用一個常見主體或兩個常見詞，再由可見光線／天氣承載結尾。

開發四例均收到 Groq HTTP 400，error code 為 json_validate_failed，沒有通過供應商結構化輸出，不執行圖片搜尋，端到端有效輸出為 0/4。應用程式看到的錯誤仍是既有 offline。不能從錯誤代碼斷定模型語意能力或圖片召回率，亦未透過重送、放寬 schema 或更動參數取得成功回答。

最終四首留出，V1 有效輸出 4/4，B 同樣 0/4（四個 json_validate_failed）。B 的 8 個預期攝影方向和 8 個預期插畫方向均未發出搜尋，因此沒有可比較的條件圖片品質；端到端取得強相關圖為 0/8。

## 結論與驗證

A 沒有提高首圖或前三張的意境契合度，B 的輸出可靠性不足，兩者均不採用。保留完整失敗分母及最終留出分數，避免只挑出有圖的案例。V1 也未達完整產品意境品質目標。

實驗工具共用正式 model adapter，僅 CLI 中替換 system message，不修改正式程式。輸出保留圖片標題、作者、來源與授權，可逐張復核。原文見 tests/experiments/visual-scenes-a.txt 及 visual-scenes-b.txt，重跑方式見該資料夾 README。Lint、TypeScript、18 項單元／整合測試通過；本輪沒有產品程式或 UI 變更。
