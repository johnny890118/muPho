# MuPho Design System

MuPho 是沉浸式音樂情緒畫廊。歌曲與意境帶使用者進入攝影或插畫，再透過收藏與分享延伸心情。歌曲找圖優先。炭黑底、暖白字與少量柔和琥珀色維持安靜，由影像提供主要視覺重點。歷史方向圖見 [UI 重構紀錄](ui-rebuild-plan.md)。

## Tokens

顏色與顯示字體的實作來源為 [app/globals.css](../../app/globals.css)。在 Tailwind 中使用語意 token。調整整體配色時更新共用定義。

| 角色 | Token | 現行值 |
| --- | --- | --- |
| 頁面底色、主要閱讀文字 | `background`、`foreground` | `#10100f`、`#f3ebe0` |
| 卡片及浮層、次要控制 | `card`、`secondary`／`muted` | `#191815`、`#24211d` |
| 次要文字、互動底色 | `muted-foreground`、`accent` | `#b8aea3`、`#302820` |
| 主操作、主操作文字、焦點 | `primary`、`primary-foreground`、`ring` | `#e7bd86`、`#21160d`、`#e7bd86` |
| 分隔線、表單框、錯誤 | `border`、`input`、`destructive` | `#39332b`、`#625649`、`#ffb0a4` |

字標、首頁標題、作品名稱使用 `font-display` 的系統 serif 字型堆疊。一般文字與控制用 PingFang TC、Microsoft JhengHei、system-ui 回退。一般內文用 `text-sm`–`text-base`，署名／次要資訊用 `text-xs` 搭配足夠對比與行高。按鈕內的歌名與歌手可分行。正式頁沿用系統字體，Playwright 的固定字型只存在測試。

間距沿用 Tailwind 4 px 刻度。小型控制與圖庫用 8 px 間距，內容群組多用 12–24 px，頁面內邊距依畫面約 10–32 px。主要觸控目標至少 44×44 CSS px。圖片與控制容器使用低調的圓角和分隔線，琥珀色聚焦於主要動作、選中及聚焦狀態。

## 元件與版型

- 沿用 [shadcn/ui 元件](../../components/ui) 的 Button、Input、Tabs、Dialog、Skeleton 與 Textarea。相同操作使用一致 variant。原生操作需保留鍵盤、可及名稱及焦點。圖示採 Lucide，僅圖示按鈕需要可讀名稱。
- [搜尋外殼](../../components/search-shell.tsx) 與 [搜尋表單](../../components/search-form.tsx) 共用歌曲和圖片模式。首頁保留主搜尋、獨立的「試試看」標籤及帶署名精選。示範在窄於 640 px 時為兩欄，較寬時為四欄。送出搜尋後採緊湊搜尋列。
- 結果採瀑布流，窄畫面兩欄、768 px 起三欄、1280 px 起四欄。作品縮圖保留比例並預留空間。首頁氛圍影像可用 `cover` 並註明裁切。預覽以 `contain` 顯示全圖，桌機側欄放資訊與操作，手機移至圖下。保留來源、作者與授權連結。
- 裝飾圖使用空替代文字。作品圖給出有意義的替代文字。保持可見焦點、鍵盤與觸控可達，Dialog 關閉時回到開啟位置。支援 reduced motion，檢查長標題、換行及橫向溢位。勿以色彩作為狀態唯一線索。
- 縮圖延遲載入。預覽優先使用已取得的較大版本，失效時退回縮圖。維持比例的載入佔位避免版面跳動。來源政策與額度見 [來源與授權](../providers-and-licensing.md)。

## 狀態

載入時保留結果位置，以 Skeleton 和可讀狀態告知進度。空結果區分來源無匹配和作品被媒材／授權政策篩除，提供可用的查詢調整。錯誤區分來源暫時失敗、上游限流、MuPho 額度及停用。可重試時提供明確認得出的控制。圖片失效時保留區塊比例及其他操作。

## UI 驗收

有影響畫面或互動的改動，用 390×844、1440×900 檢查受影響頁面與狀態，依改動加測平板或橫向。確認主要操作、文字溢位、裁切、焦點、圖片載入及設計一致性。實作後跑相應檢查，依輸出與畫面修正，再重跑受影響部分。重大視覺取捨交由使用者確認。執行方式和更新基準的步驟見 [README](../../README.md#ui-驗收)。
