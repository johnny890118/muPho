# MuPho 架構

- Next.js App Router、strict TypeScript、Tailwind CSS 4、shadcn/ui 和 Lucide。首頁共用搜尋表單，歌曲與圖片是顯式選擇，按提交才發送請求。
- `GET /api/search` 用 Zod 驗證輸入，僅允許搜尋錄音或圖片。所有上游呼叫留在伺服器。上游固定允許清單、拒絕重新導向，無任意 URL 代理。
- MusicBrainz 提供錄音 ID、演出者、專輯和版本資料。應用程式整理部分別名及歌曲視覺線索。多筆候選需選版本，高信心且只有一筆完全符合歌手和歌名時可自動選定。其餘以歌名搜尋，畫面標示 `metadata_only`。純音樂也沿用錄音資料，不會生成歌詞。使用者可選擇在瀏覽器貼上有權處理的歌詞。規則式擷取逐行辨識固定視覺詞庫，只有詞庫中的概念會用於圖片請求。原文只存在元件記憶體，外部歌詞與 AI adapter 維持停用。
- Wikimedia Commons 提供作品頁、作者、授權名稱及 URL、縮圖和描述。與 CC BY 4.0 或 CC0 1.0 欄位交叉比對，驗證 HTTPS 網域及作品路徑，透過媒體標籤、相機 metadata 與排除條件分類。取得原檔走來源頁。授權確認時間為來源資料讀取時間。
- SQLite 用交易共享全站及匿名額度。請求先讀快取，再取得上游鎖與扣款。相同查詢在快取期限內重用結果，同一服務在單機同資料庫內只允許一筆上游呼叫進行中。提供者逾時、退避及冷卻跨程序共享。
- 本機收藏保存必要作品 metadata，不保存圖檔。分享使用 Web Share 或複製文案。相似排序以已取得作品文字及比例計算。縮圖由瀏覽器向 Commons 讀取。
